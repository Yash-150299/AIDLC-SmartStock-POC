# Project Notes

## Terminology / Naming Conventions

These conventions apply to the TnD (Transport & Delivery) user stories and their Confluence SRS pages.

| Abbreviation | Meaning |
|---|---|
| **PSM** | Mobile application — **Proscan** |
| **PIW** | Web application — **Propel-i** |
| **DI** | **Delivery Inbound** |
| **DO** | **Delivery Outbound** |

### Notes
- `PSM_*` user stories (e.g. `TnD_PSM_EPC5_UST1`) describe requirements for the **Proscan mobile application**.
- `PIW_*` user stories (e.g. `TnD_PIW_EPC23_UST1`) describe requirements for the **Propel-i web application**.
- `DI` and `DO` are used throughout the module/feature names and page titles to indicate the inbound vs outbound delivery flow.
